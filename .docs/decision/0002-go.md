# 0002 — Tool written in Go

Status: accepted

## Context

Requirements: macOS, Windows and Linux; fast; low memory; small dependency
surface; small enough for an LLM to hold in context.

## Decision

Go, single static binary per platform, standard library for HTTP, JSON, zip and
CLI.

## Alternatives

- Python: matches the existing `minisign.py` but needs a runtime per OS and
  packaging work.
- Rust: fastest, but borrow/async friction raises code and token cost at this
  size.
- Node/TypeScript: matches the manager but heavier runtime and memory.

## Consequences

- `zip`, `archive/zip`, `net/http`, `encoding/json`, `crypto/sha256` cover most
  of the tool.
- Cross-compilation is trivial for CI; no cgo (see 0003).
- One non-stdlib signing dependency (0003).
